# Original project artwork

The repository's [MIT license](../LICENSE), attributed to `2026 arshiaghaf`, applies to the original project artwork listed below as well as the project source. The project owner approved these assets for inclusion and release under MIT. Third-party dependencies retain their own licenses.

## Provenance

The project's existing design provenance records six original OpenAI Image Gen character layers composed over one shared storybook badge, plus a separately generated original monkey-head mark. The two favicons derive from that head mark. The Apple touch icon combines the same head with the project's pink background treatment. These are original generated project assets, not scraped photographs or stock-art imports.
